Question 2(c): Absolute and Relative Hyperlinks

Absolute hyperlink

An absolute hyperlink contains the full web address, including https:// and the domain name. It is used to link to an external website, for example the Central Bank of Kenya.

Central Bank of Kenya

Relative hyperlink

A relative hyperlink gives only the path to a file from the current page. It is used to link to pages inside the bank's own intranet, for example the HR leave form. It keeps working even if the intranet moves to a new server, and it is shorter to write.

Leave Form

Difference

An absolute link works from anywhere because it names the exact address, while a relative link depends on where the current page is saved.
