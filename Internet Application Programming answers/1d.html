Question 1(d): Ways of Applying CSS

1. INLINE: the style is inside the tag.

2. INTERNAL: the style is in a style tag in the head.

3. EXTERNAL: the style is in a separate .css file.

Recommendation

For a large multi-page government portal, external CSS is best. One file styles every page, so a change is made once and updates everywhere. This keeps the design consistent, saves time, and the browser stores the file so pages load faster.
