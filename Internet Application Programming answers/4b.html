Question 4(b): JavaScript Events (M-Banking)

1. click

Triggered when the customer taps the Check Balance button.

2. input

Triggered each time the customer types in the amount field, so the app can show the amount being sent.

3. submit

Triggered when the customer presses Send Money, so the app can check the details before sending.

Which is preferred?

addEventListener is preferred. It keeps JavaScript separate from HTML, allows many handlers on one event, and can be removed later. The HTML attribute (for example onclick="...") mixes code into the page and allows only one handler.
