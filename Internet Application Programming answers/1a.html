Question 1(a): Key Terms

i. Tag

A tag is a keyword inside angle brackets that tells the browser how to display content. Example: <p> ... </p>

ii. Attribute

An attribute gives extra information about an element. It is written inside the opening tag as name="value". Example: <a href="index.html">

iii. Element

An element is the opening tag, the content and the closing tag together. Example: <h1>Welcome</h1>

iv. DOCTYPE declaration

The first line of an HTML page, <!DOCTYPE html>. It tells the browser the page uses HTML5.

v. Nesting

Nesting means placing one element inside another and closing them in reverse order. Example: <p>Hello <b>world</b></p>
