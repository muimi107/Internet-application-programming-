Question 2(b): Types of Lists in HTML5

1. Ordered list

Items are numbered because the order matters. It is best for step-by-step instructions, for example how to pay taxes on the KRA iTax website.

  1. Log in to iTax
  2. Select File Return
  3. Enter your details
  4. Submit the return

2. Unordered list

Items have bullets because the order does not matter. It is best for a group of items, for example the services offered on a hospital website.

  • Outpatient
  • Maternity
  • Laboratory

3. Description list

Each term is paired with its description. It is best for a glossary or FAQ, for example the meanings of terms on a SACCO website.

Dividend
The yearly share of profit paid to members.
Share capital
The money members contribute to own part of the SACCO.
