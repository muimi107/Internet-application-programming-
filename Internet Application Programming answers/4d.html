Question 4(d): The DOM

The Document Object Model (DOM) is a tree-like representation of an HTML page that the browser creates when the page loads. Every tag, attribute and piece of text becomes an object (node) in the tree.

JavaScript uses the DOM to select elements, change their content or style, and add or remove elements, so the page updates without reloading.
