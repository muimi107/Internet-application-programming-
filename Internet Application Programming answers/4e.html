Question 4(e): Functions in a Quiz App

i. Function declaration vs function expression

// Function declaration
function checkAnswer(chosen, correct) {
  return chosen === correct;
}

// Function expression
const calculateScore = function (right, total) {
  return (right / total) * 100;
};

A function declaration starts with the function keyword and a name. It is hoisted, so it can be called before the line where it is written.

A function expression stores a function in a variable. It is not hoisted, so it can only be used after the line where it is defined.

ii. Purpose of the return statement

The return statement sends a value back to the code that called the function and stops the function. In the quiz app, it gives back whether an answer is correct or the student's score, so the result can be shown or saved. Without return, a function gives back undefined.
