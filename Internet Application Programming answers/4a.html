Question 4(a): Data Types and var, let, const

Four primitive data types

  • String: text, for example "Wanjiku"
  • Number: whole numbers and decimals, for example 25
  • Boolean: true or false
  • Undefined: a variable declared with no value yet

Declarations

var, let and const

  • var: function scope, can be changed and re-declared. It can cause bugs, so it is avoided.
  • let: block scope, can be changed but cannot be re-declared in the same scope.
  • const: block scope, cannot be changed after it is given a value.

Preferred

const is preferred for values that do not change, and let for values that must change. var is avoided because its function scope and re-declaration cause hard-to-find bugs.
